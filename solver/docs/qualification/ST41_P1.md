## P1 poles — executed in release and debug

The computed generalized eigenvalues are unchanged. Before `adjeig` rescales or
rejects modal vector pairs, the diagnostic now retains the original left/right
vectors and computes the residual of `B*x=a*A*x`. On the real-family path,
DTGEVC extracts vectors from the existing real Schur factorization `(T,I)`;
it does not recompute or reorder the poles.

For each finite root, with raw vectors x and y, the reported absolute resolution
estimate is

```
r = B*x - a*A*x
w = abs(B)*abs(x) + abs(a)*abs(A)*abs(x)
gamma = 8*n*epsilon(real64)
absolute_error = [sum(abs(y)*abs(r)) + gamma*sum(abs(y)*w)] / abs(y^H*A*x)
```

The componentwise scale avoids the old fixed 1e-10 growth cutoff. This is a
first-order numerical diagnostic, particularly limited near defective roots;
it is not a mathematical certificate of Lyapunov stability. Raw poles, raw
maximum growth, and the count of positive raw real parts remain reported.
Positive growth is identified as resolved only when it exceeds the local
resolution estimate and the scaled eigenproblem residual is at most 1e-10.
Missing/failed evidence is indeterminate. Numerically unresolved signs remain
`MARGINAL_UNRESOLVED`, which makes no physical stability claim.

The definition `delta=-2*pi*growth/abs(omega)` is retained for resolved
oscillatory roots. An optional resolution argument lets the spectrum audit
identify an unresolved imaginary part without silently turning it into a
well-defined oscillatory decrement. Existing raw modal/response values and
the existing modal-vector qualification threshold are preserved.

An independent DSYGV `K*phi=lambda*M*phi` reference is reported only when rpm
is exactly zero, damping exactly zero, and K/M are exactly real symmetric.
The mass must pass the generalized solver's positive-definiteness requirement;
K may be semidefinite or indefinite. The reference reports each lambda,
componentwise uncertainty and residual. No nonsymmetric matrix is symmetrized
and no eigenvalue is clamped to zero or forced onto the imaginary axis.

and before/after outputs under `build/st41-p1/poles/`. Section garbage collection
links the selected production routines without numerical stubs.

Ten matrix controls (five physical models through both DGGEVX and the real

were byte-identical between original and corrected code in those controls.

The final control deliberately reveals an inherited precision limitation:
DGGEVX produced growth 8.881784192560356e-13 s^-1 and a frequency error of
approximately 3.0511e-10 rad/s, with scaled residual 7.6278e-11 and estimated
absolute resolution approximately 3.0516e-10 s^-1. Its result cannot establish
the growth sign. The Schur route on the same input resolves growth
9.999999999999998e-13 s^-1 and reports instability. The diagnostic exposes that
difference instead of labelling the physical model stable or hiding a resolved
positive root. The retained numerical limitation is not claimed as corrected.

The generic `simple2b-sp` Campbell control also reproduces the original false
instability label: at 0 rpm, raw maximum growth was 1.5358542925764175e-7 s^-1
and 36 roots passed the old fixed growth threshold. With the new evidence,
all 88 roots have diagnostics and the status is `MARGINAL_UNRESOLVED`; the raw
maximum growth remains identical. The independent DSYGV reference contains
44 positive stiffness eigenvalues, no negative values, and maximum residual
approximately 1.1241e-11. This is a generic numerical control, not ST41.

## P1 Campbell presentation

Every requested presentation speed is now a mandatory target of the same
adaptive continuation used to discover and refine physical intersections.
CPBSPD remains the initial requested sample count. The maximum initial step,
association rejection/refinement rules, topology-event checks, root residual
and speed criteria, and internal capacities remain unchanged.

Both real-family and legacy-vector paths pass each added target through the
existing physical eigensolve and continuation. Publication copies an accepted
sample; it does not solve or reseed modes independently and no longer linearly
interpolates the frequency table. A missing accepted target is an explicit
error. `DISPLAY_POINT index rpm RESOLVED accepted_index` identifies each target
and its source in the accepted history. `RESOLVED` here means an actual
eigensolve at that speed; growth-sign uncertainty remains separately visible
in the spectrum-quality records. Existing unavailable spectral-group slots
remain unavailable. Identity notes distinguish instantaneous frequency rank,
continued modal vectors, and slots in the final spectral-group frequency
multiset; none claims a unique pole genealogy through a merged group.

Endpoints use their exact requested values. Interior presentation targets use
the same arithmetic during scheduling and lookup. A proposal lying at most
four representable floating-point increments below the next target is moved
forward to that target, then subjected to the unchanged association checks.
The `NEAREST`-based guard avoids inserting artificial tiny intervals when
CPBSPD and INTSPD describe the same grid. It is not a physical root or tracking
tolerance. Nonrepresentable distinct display grids fail before continuation.
The family capacity stays 1024; the vector capacity stays 500. Adding mandatory
presentation targets can consume more history storage; if their union with
adaptive samples exceeds that capacity, the existing explicit failure remains.
No sample truncation or forced mode association is introduced.

The public `run_campbell_vectors` route is also executed directly on a native
manufactured model, linked with every production object except the replaced
main program. It uses the actual `prpkc`, `adjeig`, modal association, physical
root refinement and output routines, without numerical stubs:

```
M = diag(1, 2), K = diag(4, 18), G = [[0, 0.15], [-0.15, 0]]
D(Omega) = Omega*G, range = 0..60 rpm
```

CPBSPD 5/25 produces identical 50-point plots through this route. A separate
CPBSPD 500 / INTSPD 500 case accepts exactly 500 spectra and publishes exactly
500 resolved points, preserving the existing vector capacity. All three
controls pass in release and debug. The independently derived characteristic
polynomial is

```
2*w^4 - (26 + 0.15^2*Omega^2)*w^2 + 72 = 0.
```

The comparator checks each displayed frequency against that polynomial and
the two synchronous intersections against its `w=Omega` roots. Maximum printed
frequency error is approximately 5.101e-11 Hz. The intersection error is at
most 2.462e-7 rpm, well below the unchanged requested regression target.

An independent read-only review of both scheduling paths found no identity
reseed, publication-only eigensolve, relaxed association/root criterion, or
capacity increase. The preceding pole review additionally exercised resolved
positive roots alongside invalid roots, bad-residual roots and absent evidence;
resolved positive growth remained visible as incomplete-spectrum instability.

Final ordinary regressions also passed with the existing Makefile in both
profiles: all 16 LAPACK smoke checks, the Campbell stdio case, and the selected
modes stdio case. Each critical-speed comparison checked the same 27 frozen
values and retained the original tolerances; largest difference was 2e-6 rpm.
Logs are `build/st41-p1/final-test-release.log` and `final-test-debug.log`.
`make verify`, `make verify-layout` and `git diff --check` passed.

These controls qualify the general implementation and preserve the observed
old failure. Exact ST41 seven-1X/23-intersection acceptance remains blocked by
the absent ST41 deck and recorded samples. Finite adaptive coverage continues
to be reported as such; it is not proof of every possible tangent crossing on
a continuous speed interval.
